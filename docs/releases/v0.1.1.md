# cad-render v0.1.1

Prebuilt multi-arch image, production compose default, AGPL-3.0 licence and the repository documents.

## Highlights

- **Prebuilt image** `ghcr.io/rojosinalma/cad-render` for `linux/amd64` and `linux/arm64` (tags
  `<version>`, `<major>.<minor>`, `latest`, `sha-<short>`), published by GitHub Actions. The `zoo`
  CLI is fetched per architecture with a pinned checksum, so `/zoo` works on arm64 too.
- **`compose.yaml` runs the published image in production mode**; `compose.override.yaml.example`
  is the development variant (local build, `.:/app` mount, live reload).
- **Docs**: `CONTRIBUTING.md`, `docs/SDD.md`, topic docs for the CLI, API, writing parts,
  configuration, security and development; `SECURITY.md`, `CODE_OF_CONDUCT.md`, issue and PR
  templates; Dependabot; a `run-tests` check workflow.
- `HEALTHCHECK` baked into the image.
- Security: `pillow` 12.3.0, `puma` 7.2.1.

## Breaking changes

- **Licence is now AGPL-3.0** (was MIT). Hosted modified copies must publish their source.
- `bin/deploy-rsync` was removed; pull the image on the target host instead.
- `compose.yaml` no longer mounts the checkout or runs in development mode; copy
  `compose.override.yaml.example` to `compose.override.yaml` to get that back.

## Upgrade notes

```sh
git pull
docker compose pull && docker compose up -d     # or CAD_IMAGE_TAG=0.1.1 in .env
curl http://localhost:9292/health               # "version":"0.1.1"
```
